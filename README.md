# Lab Slot Scheduler

## Project ID: PRJ069

### Project Description
Lab Slot Scheduler is a web-based application designed to manage and schedule laboratory slots efficiently.

### Objective
- To manage laboratory time slots.
- To avoid slot booking conflicts.
- To allow students to book available lab slots.
- To view and update slot details.

### Technologies Used
- Python
- FastAPI
- HTML
- CSS
- JavaScript

### Backend Features
- Create lab slots
- View all lab slots
- View individual slot details
- Book or update slots
- Delete lab slots

### How to Run
1. Install Python.
2. Install dependencies using:
   pip install -r requirements.txt
3. Run the backend:
   uvicorn main:app --reload
4. Open http://127.0.0.1:8000/docs

### Project Status
Backend API implemented using FastAPI.
